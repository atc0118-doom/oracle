# ORACLE
World Risk Intelligence dashboard.

## Features
- Real-time public-source news ingestion through Vercel API route
- 60 second auto refresh
- Automatic global risk score calculation
- AI-assisted rule-based assessment
- Auto-updating hot regions and WHY SCORE modal
- Admin terminal: `?admin=doom`

## Notes
Reuters/AP/BBC direct APIs are not bundled. The serverless API uses public GDELT article signals and displays monitored source families for situational awareness.
